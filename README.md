# FrameBoard

**FrameBoard** — нативное macOS-приложение для видеомейкеров, режиссёров монтажа и продюсеров: разбор видео на стоп-кадры, автоматическая раскадровка сцен, цветовые палитры и заметки режиссёра.

**Автор:** [Антон Белый](https://github.com/MarvelTrade)

## Возможности

1. **Режим «Лица и ведущие» (для обложек и интервью)**
   - **Первая минута (быстро):** сканирует первые 60 секунд и за несколько секунд отбирает по 3–5 лучших кадров каждого ведущего/героя по резкости, открытым глазам, позе и свету.
   - **Всё видео:** полный анализ по лицам на всю длительность.
2. **Режим «Раскадровка и референсы» (для клипов, мультиков и рилсов)**
   - **По смене сцен (`Scene Detection`):** автоматически находит каждую монтажную склейку.
   - **Посекундно:** шаг `0.5с`, `1с`, `2с`, `5с`.
   - **Ритм монтажа:** расчёт длительности каждого плана и среднего темпа клипа.
3. **Палитра цветов кадра (HEX Swatches)**
   - Автоматически извлекает 5 доминирующих цветов (HEX) из каждого кадра для анализа цветокоррекции и референсов.
4. **Заметки режиссёра и экспорт**
   - Комментарии под каждым планом с автосохранением.
   - Сводная таблица **Contact Sheet (`contact_sheet.jpg`)** с таймкодами и палитрами.
   - Экспорт в **HTML (Лист режиссёра)** и **Markdown**.

## Сборка и запуск

Требования: macOS 14+, Swift 6+, `ffmpeg` (`brew install ffmpeg`), Python 3.11+ с зависимостями из `engine/requirements.txt`.

```bash
chmod +x build_app.sh
./build_app.sh
```

Готовое приложение появится в `.build/FrameBoard.app`.
